# Third-Party Components

This package exposes generic Google Cloud integration modules and configuration
references derived from a community publishing project. Application logic,
content, media and operational data are not included.

The declared dependency `@google-cloud/firestore` version `7.11.0` is Google's
Firestore Node.js client, distributed under Apache-2.0. Its transitive
dependencies carry their own terms. Node.js, container images, Firebase CLI,
Google Cloud CLI and build tools are separate third-party software.

No vendored SDK or resolved dependency tree is bundled. Before redistributing
installed dependencies or containers, retain their LICENSE/NOTICE files and
review the exact resolved components. [RIGHTS.md](RIGHTS.md) does not override
third-party permissions or attribution obligations.
